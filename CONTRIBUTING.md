# Working on Arco

Keep commits atomic: one behavior, one visual concern, or one documentation change per commit. Keep formatting separate from behavior changes. Use concise messages that describe the result. Do not squash unrelated changes into one commit.

Preserve the repository owner's configured author and committer identity. Do not add automated co-author trailers.

Check changed JavaScript with `node --check`. Keep in-app learning claims honest: self-reported movement is not verified technique, and proposed school partnerships are not confirmed programs.
